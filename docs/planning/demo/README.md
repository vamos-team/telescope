# Telescope v02-canvas 데모 초안

[index.html](index.html)을 내려받아 브라우저에서 열면 됩니다. v02-canvas 화면 흐름을 검토하기 위한 초안입니다. [화면설계 이슈 #68](https://github.com/vamos-team/telescope/issues/68)

## 데모 흐름

상단 첫 버튼 ‘목록 보기’에서 부서 캔버스를 선택합니다. 왼쪽 사이드바는 탭 왼쪽 아이콘으로 닫을 수 있습니다.

1. **예시 불러오기**: 상단 `+ 자료 추가`를 열고 `예시 불러오기`를 누르면 공시 표, 비교, IR·뉴스·사내 자료, 메모와 관계 연결을 볼 수 있습니다.
2. **자료 올리기** (`+ 자료 추가`)
   - 공시: 계정 검색 → 누르면 원본 표에서 행 선택, 끌어다 놓으면 찾은 행만 카드로
   - IR·뉴스: 주제 검색(키워드 + 개념 사전) → 캔버스로 드래그 또는 +
   - 사내 자료: 파일 올리기 → 파서 요약 카드 (데모는 txt·md·csv만 읽고 수치를 뽑음)
3. **온톨로지 연결**: 카드 오른쪽 점을 다른 카드로 끌면 관계(근거·설명·반박·관련) 연결. 연결선을 누르면 관계 변경·삭제. 같은 개념을 가진 문서·표 카드는 점선으로 자동 연결
4. **팀 공유(목업)**: 캔버스 도구에서 작성자를 바꾸면 왼쪽 사이드바의 `활동 로그`에 그 이름으로 기록됩니다.
5. **컨텍스트 추출**: L0 system ~ L4 요청 층으로 묶은 프롬프트, 층별 해시. `프롬프트 복사`, `messages JSON`
6. **결과물 생성**: 투자계획서·사업기획서·예산서 초안. 문장마다 근거 ID, 누르면 해당 카드로 이동. 근거 없는 항목은 `근거 부족`
7. **질문 → 평가**: 애널리스트 예상 질문을 만들고, 2Q26 리포트 쟁점과 견줘 정밀도·재현율, 초안 가정과 2Q26 실적 차이를 표시

AI 기능(초안, 질문, 평가)은 규칙 기반 목업입니다(`_build/src/local/ai.ts`). 같은 캔버스면 항상 같은 결과가 나옵니다.
브라우저 콘솔에서 `__aiSelfCheck()`로 판정 규칙을 점검합니다.

## 구성

- `_template/frontend`와 화면 코드를 공유하고, 서버 호출(`src/api.ts`)만 `_build/src/local/server.ts`로 바꿨습니다.
- server.ts: `_template/backend`의 검색(bigram BM25 + 개념 사전, RRF), 비교, 이벤트 리듀서, 컨텍스트 컴파일러(`context/compiler.py`)를 옮기고 문서·메모·연결 이벤트를 더했습니다.
- 캔버스와 활동은 브라우저에 저장합니다. 임베딩 검색과 LLM 호출은 목업 범위에 포함되지 않습니다.

## 데이터

`data/`에는 SKT·KT·LGU+ 예시가 들어 있습니다. **재무 수치·기사·링크는 모두 데모용 목업**입니다.

| 파일 | 내용 |
|---|---|
| `manifest.json` | 어떤 XML·CSV를 어느 회사로 읽을지 |
| `KT_2026Q1.xml` | KT 분기보고서 (DART XML 형식) |
| `SKT_2026Q1_is.csv`, `_bs.csv` | SKT IR 손익·재무상태표 |
| `LGU_2026Q1_is.csv`, `*_2026Q1_rp.csv` | LGU+ 손익 및 3사 특수관계자 거래 표 |
| `sources.json` | IR·뉴스와 사내 자료 (요약, 핵심 수치, 개념 태그, 출처 링크) |
| `analysis.json` | 결과물 양식(섹션·태그), 질문 뱅크, 다음 분기(2Q26) 실적과 리포트 쟁점 |
| `examples/` | 백엔드로 낸 기대 결과 (이전 목업 회사명 기준, 대조용) |

- 데이터는 원본 작업공간의 `demo/_build/make_data.py`에서 `_template/backend`의 파서를 사용해 생성합니다. 여기에는 변환 결과인 `_build/src/local/data.json`도 포함돼 있습니다.
- 결과물 양식, 질문, 평가 기준은 코드가 아니라 `analysis.json`에서 바꿉니다.

## 다시 빌드

```bash
cd _build
npm ci
npm run build  # → ../index.html
```

`data/`를 바꿔 데이터 JSON을 다시 생성할 때는 원본 작업공간의 `demo/_build`에서 스크립트를 실행하고 변환 결과를 복사합니다.
