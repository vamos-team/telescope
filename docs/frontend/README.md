# Telescope 프런트엔드 설계

`docs/frontend/`에서 화면 정보 구조(IA), 프런트엔드 API 명세, 컴포넌트 아키텍처를 관리합니다. v02-canvas 화면설계는 [이슈 #68](https://github.com/vamos-team/telescope/issues/68)에서 진행합니다.

- 최신 반영: 페이지 = 캔버스 + 분석 두 화면(아이콘 레일). 캔버스는 좌우 사이드바(근거 데이터 · 메모 / 자료 검색), 로컬 데이터 입력 검증(포맷 · 4사 회사), 서버 모드 대상 회사 선택·파일별 업로드·작업 조회, 메모 하나로 통일(카드 메모 · 메모 카드 · 선 메모), Shift 다중 선택 → 표 · 시각화 생성. 분석은 검토(주장 · 근거 충분/부족 · 지적 박스 · AI 인사이트) → 질문(애널리스트 리포트) → 평가(다음 분기 자료 뒤), 세션은 본인만(캔버스가 바뀌면 업데이트(같은 세션의 새 버전) · 새로 분석하기(새 세션), 세션 지우기는 목록에서 숨김. 결과는 고치지 않고 쌓음). 공통 계정이 없는 표 생성은 행을 그대로 모음, 메모는 여러 카드에 연결. `demo.html`은 아직 다시 빌드하지 않음
- [v02-canvas 데모 초안](../../frontend/README.md): 코드는 `frontend/`, 빌드된 한 파일은 [`docs/frontend/demo.html`](demo.html)
