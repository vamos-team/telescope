최종 화면설계에 따른 기획 문서 수정은 #28의 `docs/planning/`에서 관리합니다. IA에는 현재 설계, 데모의 구현 범위와 확정이 필요한 항목을 구분해 기록합니다. Figma 화면과의 일치 검증은 별도 진행 대상입니다.
